# data-labs

A collection of data science and data engineering projects documenting my learning journey across three areas.

## Projects

### [scrape-my-site](scrape-my-site/)
Web scraping scripts and experiments, including multi-threaded scraping implementations.

### [pipe-my-data](pipe-my-data/)
Data engineering notes and mini-projects covering tools like Apache Spark, Kafka, Airflow, PostgreSQL, and Docker. Includes hands-on pipeline projects using real datasets (GitHub Archive, tweets, Netflix).

### [ds-training-2018](ds-training-2018/)
Data science portfolio with analysis and ML projects across domains: tabular data (Titanic, House Prices, FIFA 19), computer vision (MNIST, Amazon from Space), and mathematical foundations (linear algebra, PCA, backpropagation).
